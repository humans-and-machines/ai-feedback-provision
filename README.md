# AI Assistance for Discretionary Work

## Repository structure

- `analysis/`: Notebooks for descriptive feedback quality analysis, regression models, and result visualizations.
- `data/`: The anonymized experiment dataset plus feedback quality ratings and related data.
- `tables/`: Generated course-level, homework-level, and stratified summary results for shared and treatment-only outcomes.
- `requirements.txt`: Python dependencies required to run the notebooks.
